# IT Support Automation Toolkit

A practical PowerShell-based IT Support and Infrastructure Automation project.

This project demonstrates how PowerShell can be used to automate common IT support, system administration, and troubleshooting tasks.

## Project Objectives

The toolkit is designed to help IT Support Engineers quickly collect system information, diagnose network problems, monitor disk space, check Windows services, and perform a general system health check.

## Technologies Used

- PowerShell
- Windows Administration
- Networking
- DNS
- TCP/IP
- System Monitoring
- IT Support Automation
